# COLUM Brand Assets

COLUM — desktop controlling AI assistant.

### Main
- icon.png — primary 1024×1024 app icon
- icon.ico — Windows multi-size icon
- banner.png — horizontal brand banner
- wordmark.png — COLUM wordmark
- favicon.png — website favicon
- icon-transparent.png — transparent icon
- icon-dark.png — dark-mode icon
- banner-dark.png — dark-mode banner
- icon.svg — SVG wrapper containing the high-resolution artwork

### PNG sizes
16, 32, 48, 64, 128, 256, 512 and 1024 px versions are included.

### Recommended use
Windows app/installer: icon.ico
Desktop launcher: icon.png / icon-256.png
System tray: icon-32.png / icon-48.png
Website/PWA: favicon.png
Website/branding: banner.png / wordmark.png
Dark UI: icon-dark.png / banner-dark.png
