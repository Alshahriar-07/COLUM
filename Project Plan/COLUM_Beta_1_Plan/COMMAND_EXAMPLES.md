# COLUM Beta 1 Command Examples

## Activation
"COLUM"

## Apps
"COLUM, open Chrome."
"COLUM, switch to VS Code."

## Screen
"COLUM, look at my screen and explain this error."

## Web
"COLUM, research the latest AI news and summarize the important items."

## Files
"COLUM, find my COLUM project folder."
"COLUM, create a notes file."

## Coding
"COLUM, run the tests and tell me why they failed."

## Workspace
"COLUM, switch to Research."

## Control
"COLUM, stop the current task."

## High-risk
"COLUM, delete these files." → confirmation required by default.
"COLUM, send this message." → confirmation required by default.
